🎮 Hangman Game

A simple and interactive Hangman Game developed using Python.
The player has to guess the hidden word letter by letter before all attempts are exhausted.

This project was created as part of the CodeAlpha Internship to practice Python fundamentals, loops, conditions, and string handling.

✨ Features
Random word selection
Limited attempts system
User-friendly command-line interface
Input validation
Win/Lose conditions
Beginner-friendly Python project
🛠️ Tech Stack
Python
🚀 How to Run
python hangman.py
